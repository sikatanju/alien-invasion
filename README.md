## Introduction
Alien Invasion is a classic arcade-style space shooter game built with Python and Pygame. Players control a spaceship and defend Earth from waves of descending aliens. This simple yet engaging game demonstrates fundamental game development concepts while providing entertaining gameplay.

<br />

## Key Features
- **Player-Controlled Spaceship:** Navigate your ship horizontally across the bottom of the screen...
- **Alien Fleet Movement:** Challenging waves of aliens that move across and down the screen...
- **Projectile System:** Fire bullets to destroy the invading aliens...
- **Progressive Difficulty:** Game becomes increasingly challenging as you advance...
- **Score Tracking:** Keep track of your high scores across game sessions...

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sikatanju/alien-invasion.git
   ```

2. Navigate to the project directory:
   ```bash
   cd alien-invasion
   ```

3. Install Pygame:
   ```bash
   pip install pygame
   ```

4. Run the game:
      ```bash
   python alien_invasion.py
   ```

<br />

## Usage

1. Start the Game
   - Run the game using the command above
   - Press 'Play' on the start screen to begin

2. Game Controls
   - LEFT ARROW: Move ship left
   - RIGHT ARROW: Move ship right
   - SPACEBAR: Fire bullets
   - Q: Quit game

3. Gameplay
   - Destroy all aliens to advance to the next level
   - Avoid alien collisions with your ship
   - Prevent aliens from reaching the bottom of the screen
   - Each level increases in difficulty with faster aliens

4. Scoring
   - Earn points for each alien destroyed
   - Track your high score across game sessions
